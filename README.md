# US Stock Scout 🇺🇸

ตัวช่วยคัดหุ้นอเมริกา (S&P 500 + Nasdaq-100) แยก **ระยะสั้น (~4 สัปดาห์) / กลาง (6–18 เดือน) / ยาว (1–5 ปี+)**
และแยกตามอุตสาหกรรม พร้อมข้อมูลจริงย้อนหลังและบทวิเคราะห์รายตัว ส่งเข้า Telegram ทุกเช้าวันทำการ (06:15 เวลาไทย)

> ใช้ประกอบการตัดสินใจเท่านั้น ไม่ใช่คำแนะนำการลงทุน ไม่รับประกันกำไร

## ส่งอะไรเข้า Telegram (แบบย่อ อ่านง่าย)
1. **สรุปเช้านี้** — สภาพตลาด 1 บรรทัด + Top 5 ต่อระยะ (สั้น/กลาง/ยาว)
   แต่ละตัว 1 บรรทัด: 🟢/🟡 + ชื่อหุ้น + กลุ่ม + เหตุผลภาษาคน + ข้อควรระวัง
2. **Heatmap อุตสาหกรรม** (รูป) — ขนาด = มูลค่าบริษัท, สี = ผลตอบแทน 1 เดือน
3. **การ์ดอันดับ 1 ของแต่ละระยะ** — เกรด A–F (เติบโต/คุณภาพ/ราคา/โมเมนตัม/ความนิ่ง),
   เหตุผล, ข้อควรระวัง, สถิติจริงถ้าถือ 4 สัปดาห์, ราคาเป้านักวิเคราะห์, ปุ่มเปิดกราฟ
4. **สรุปผลทดสอบย้อนหลัง** — สัปดาห์ละครั้ง (เช้าวันเสาร์ จากข้อมูลวันศุกร์)

รายงานฉบับเต็ม (ตัวเลขทุกตัว) อยู่ในไฟล์ `report_full_*.txt` ใน artifact ของ Actions
รูปแบบอ้างอิงจาก Seeking Alpha / Zacks / TipRanks (เกรด, คำตัดสินเดียว), Infoquest / InnovestX
(ลิสต์สั้น หน้าตาเหมือนกันทุกตัว), Liberator (ตลาด 1 บรรทัดบนสุด, เหตุผลสั้น), Finviz (heatmap)

## เกณฑ์ (มาจากงานวิจัยที่ตีพิมพ์ ไม่ได้ปรับจูนกับข้อมูล)
| ระยะ | ปัจจัย | ทดสอบย้อนหลังได้? |
|---|---|---|
| สั้น | โมเมนตัม 6 และ 12 เดือนแบบข้ามเดือนล่าสุด (Jegadeesh–Titman), ใกล้ high 52 สัปดาห์ (George–Hwang), ต้องอยู่เหนือเส้น 200 วัน | ✅ ใช้แค่ราคา |
| กลาง | กำไร/รายได้โต (แนว CAN SLIM, PEAD), ราคาเป้า+เรตติ้งนักวิเคราะห์ (≥5 คน), โมเมนตัม 6 เดือน | ❌ ไม่มีงบย้อนหลังแบบ ณ เวลานั้น |
| ยาว | ROE, gross/operating margin (Novy-Marx, QMJ), หนี้ต่ำ, รายได้โต, FCF yield, Fwd P/E — **เทียบในอุตสาหกรรมเดียวกัน** | ❌ เหตุผลเดียวกัน |

คะแนน = ค่าเฉลี่ยของ percentile rank (0–100) ของแต่ละปัจจัย

## ข้อจำกัดที่ต้องรู้
- **Survivorship bias**: ทดสอบย้อนหลังด้วยรายชื่อหุ้นในดัชนีวันนี้ → ผลย้อนหลังดูดีเกินจริง
- งานวิจัยพบว่าผลตอบแทนของปัจจัยลดลงราว 58% หลังตีพิมพ์ (McLean & Pontiff 2016)
- ข้อมูลพื้นฐาน/นักวิเคราะห์มาจาก Yahoo Finance (ผ่าน yfinance) อาจผิดหรือขาด
- ค่าธรรมเนียมใน `config.yaml` (`fees.per_side_pct`) เป็น **ค่าสมมติ** — ใส่ต้นทุนจริงของ Dime
- ยังไม่ได้ตรวจว่า Dime มีหุ้นทุกตัวในลิสต์ — เช็กในแอปก่อนซื้อ

## ติดตั้ง
1. สร้างบอทใหม่กับ @BotFather → ได้ token; ส่งข้อความหาบอท แล้วเปิด
   `https://api.telegram.org/bot<TOKEN>/getUpdates` เพื่อดู `chat.id`
2. Repo → Settings → Secrets and variables → Actions → เพิ่ม `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
3. Actions → **Daily US Stock Scout** → Run workflow (ลอง `limit=30` ก่อนเพื่อทดสอบเร็ว)

## รันเอง
```bash
pip install -r requirements.txt
python scout_run.py --demo        # ข้อมูลสังเคราะห์ ไม่ต้องใช้อินเทอร์เน็ต
python scout_run.py --limit 30    # ข้อมูลจริง 30 ตัวแรก
python scout_run.py --notify      # ข้อมูลจริงทั้งหมด + ส่ง Telegram
pytest -q
```
ผลลัพธ์ (รายงาน, คะแนนทุกตัว CSV, รอบทดสอบย้อนหลัง) อยู่ใน `output/` และเป็น artifact ของ Actions 30 วัน
